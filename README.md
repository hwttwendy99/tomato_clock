# 🍅 Tomato Clock

像素风格的番茄时钟。单文件运行，用来专注工作、管理待办，并按经典番茄钟节奏切换休息。

## 功能

- **番茄计时**：默认 25 分钟专注、5 分钟短休息；每完成 4 个专注进入 15 分钟长休息
- **待办列表**：左侧添加、删除事项；当前任务显示在标题和倒计时中间
- **完成后自动勾选**：专注倒计时自然结束后，当前任务会标记为完成，并切到下一条未完成事项
- **任务锁定**：计时开始后（含暂停）不能切换到其他事项，会提示 `Another task in progress.`
- **提示音与桌面通知**：阶段结束时播放提示音；若浏览器已授权通知，也会弹出提醒
- **本地保存**：任务和设置保存在浏览器 `localStorage`，刷新后仍在

## 快速开始

用浏览器直接打开 `index.html` 即可。

也可以在项目目录启动本地服务：

```bash
python3 -m http.server 8080
```

然后访问 [http://127.0.0.1:8080](http://127.0.0.1:8080)。

## 使用说明

### 计时

| 按钮 | 作用 |
| --- | --- |
| **START / PAUSE** | 开始或暂停当前阶段 |
| **STOP** | 停止并重置当前阶段时间，不会把任务标为完成 |
| **SKIP** | 跳过当前阶段，进入下一阶段，不会把任务标为完成 |

专注时间走完后会自动进入休息；休息结束后回到专注。若在设置里打开 **Auto Start**，下一阶段会在 3 秒后自动开始。

### 待办

1. 在左侧输入事项，按回车或点击 `+` 添加
2. 未开始计时时，点击某条待办即可设为当前任务
3. 开始计时后，点击其他事项会弹出提示，3 秒后消失，也可手动关闭
4. 专注倒计时结束后，当前事项自动完成

### 设置

点击右上角 ⚙ 可调整：

- Work Duration（专注时长，默认 25 分钟）
- Short Break（短休息，默认 5 分钟）
- Long Break（长休息，默认 15 分钟）
- Long Break Interval（几个专注后进入长休息，默认 4）
- Auto Start（是否自动开始下一阶段，默认关闭）
- Sound Alerts（提示音，默认开启）

## 快捷键

输入框内输入时快捷键不会触发。

| 按键 | 作用 |
| --- | --- |
| `Space` | 开始 / 暂停 |
| `Ctrl + R` | 重置当前阶段（等同 STOP） |
| `Ctrl + S` | 跳过当前阶段（等同 SKIP） |
